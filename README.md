# Inner Angel

App personal de entrenamiento auditivo funcional (PWA).

- **IV – V – I**: toca la cadencia en Do mayor para fijar la tonalidad.
- **Nota**: toca una nota aleatoria (C2–C6). Mientras no la adivines, el botón la repite.
- **12 notas**: adivina la nota. Verde = correcto, rojo = incorrecto.

## Publicar (GitHub Pages)
1. Sube estos archivos a un repo `inner-angel` en GitHub.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Abre `https://<usuario>.github.io/inner-angel/` en Chrome del celular → menú ⋮ → **Instalar app**.

## Actualizar
Edita, haz push y sube la versión en `sw.js` (`inner-angel-v2`, …) para que el celular tome los cambios.
